## AI 阅读建议

如果你是接手本项目的 AI，请按以下顺序：

1. 读 `AGENTS.md`
2. 读 `README.md`
3. 读 `docs/PROJECT_LOGIC_MANIFEST.md`
4. 读 `frontend/src/router/index.ts`
5. 读 `frontend/src/pages/AppWorkspacePage.vue`
6. 读 `backend/app/main.py`

然后再进入具体模块文件。

判断当前前端页面是否有效时，以 Vue Router 和 `AppWorkspacePage.vue` 为准；不要把 simple、legacy、backup、unused 或历史阶段材料当作当前 canonical 页面。
