# 启动与演示说明

最后更新：2026-04-21

本文档说明当前仓库的真实运行方式。项目是慢病辅助诊疗业务系统，不是完整 HIS。

## 1. 后端启动

Python 依赖由 conda 环境管理。

```powershell
cd E:\CTpath-master
conda activate ctpath
uvicorn app.main:app --reload
```

默认地址：

- API: `http://127.0.0.1:8000`
- OpenAPI: `http://127.0.0.1:8000/docs`

后端入口：

- `app/main.py`

当前主要中间件：

- `TraceIdMiddleware`
- `GlobalExceptionMiddleware`
- `JWTAuthMiddleware`
- `CORSMiddleware`
- SlowAPI rate limit handler

当前主要 API：

- `analytics`
- `attachments`
- `audit`
- `auth`
- `authz`
- `drug_permissions`
- `drugs`
- `governance`
- `patient_medications`
- `patients`
- `predictions`
- `worklists`

## 2. 前端启动

前端依赖由 npm 管理。

```powershell
cd E:\CTpath-master\frontend
npm install
npm run dev
```

默认地址：

- Web: `http://127.0.0.1:5173`

前端构建：

```powershell
cd E:\CTpath-master\frontend
npm run build
```

## 3. demo / mysql 模式

系统根据 `CTPATH_DB_URL` 判断运行模式。

### demo 模式

不配置 `CTPATH_DB_URL` 时使用 demo store。

特征：

- 启动快
- 适合演示
- `/api/health` 返回 `mode=demo`

### mysql 模式

配置 `CTPATH_DB_URL` 后使用 MySQL。

示例：

```powershell
$env:CTPATH_DB_URL="mysql+pymysql://root:your_password@127.0.0.1:3306/ctpath?charset=utf8mb4"
uvicorn app.main:app --reload
```

初始化示例：

```powershell
Get-Content .\app\mysql_schema.sql | mysql -u root -p ctpath
Get-Content .\app\mysql_seed_demo.sql | mysql -u root -p ctpath
```

## 5. 当前主要演示路径

### 医生路径

1. 打开 `/login`
2. 使用 `demo_clinic / demo123456` 登录
3. 进入医生工作台
4. 选择待处理患者
5. 打开患者详情
6. 查看左侧档案/附件、中间病程时间线、右侧用药/建议
7. 可进入模型洞察、药品管理、药品权限、治理中心

### 护士路径

1. 使用 `demo_nurse / demo123456` 登录
2. 进入护士随访工作台
3. 查看今日随访、未接通联系、医生复核队列和联系记录

### 档案员路径

1. 使用 `demo_archivist / demo123456` 登录
2. 查看患者档案、药品管理、药品权限和治理相关模块
