## UI Requirements

Screenshots should be:

- clean
- readable
- not overly colorful
- not crowded
- consistent in spacing
- suitable for undergraduate thesis

## Do Not Include

Do not include:

- billing
- inpatient
- insurance settlement
- pharmacy inventory
- training center
- CSV import
- unrelated OpenHIS screenshots

## Layout Suggestion

Use a consistent medical workbench style:

- left sidebar
- topbar
- white content cards
- light blue-gray background
- consistent table style
- clear page title and description
